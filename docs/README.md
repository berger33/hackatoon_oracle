## Como pedir um documento

Basta descrever o documento desejado (tema, público e formato). Exemplos:

- "Gere um one-pager do projeto para investidores"
- "Escreva o documento de arquitetura com o diagrama dos componentes"
- "Crie o roteiro de 3 minutos para o pitch final"
