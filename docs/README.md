# Documentos do projeto — hackatoon_oracle

Esta pasta é o espaço de trabalho para os documentos gerados durante o hackathon.

## Estrutura sugerida

| Pasta | Conteúdo |
| --- | --- |
| `docs/pitch/` | Apresentação, roteiro do pitch e one-pager |
| `docs/tecnico/` | Arquitetura, decisões técnicas e guia de uso |
| `docs/produto/` | Visão do produto, personas e roadmap |
| `docs/negocio/` | Canvas, análise de mercado e modelo de receita |

> As pastas acima são criadas conforme a necessidade — comece pelo tipo de documento que você precisa.

## Como pedir um documento

Basta descrever o documento desejado (tema, público e formato). Exemplos:

- "Gere um one-pager do projeto para investidores"
- "Escreva o documento de arquitetura com o diagrama dos componentes"
- "Crie o roteiro de 3 minutos para o pitch final"
